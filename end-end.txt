# AI Browser Automation Platform — Full Product Architecture

I want to build a full-stack AI Browser Automation Platform using local LLMs.

The platform should allow users to upload or create browser automation flows in natural language, and then automatically execute those flows inside a real browser using AI agents.

This is NOT traditional Selenium scripting.

The AI agent should reason about the UI dynamically and interact like a human user.

---

## CORE IDEA

Users can:

* Create automation flows
* Upload QA/browser tasks
* Run telecom/payment/admin portal tests
* Watch browser execution live
* View logs/screenshots/results

The system should use:

* Local LLM (Qwen2.5:14b — 7cdf5a0187d5 — 9.0 GB)
* Browser AI agents
* Real Chromium browser automation
* Web dashboard UI

Everything should run locally/private.

---

## MAIN GOAL

Build an AI agent platform that can:

1. Read human instructions
2. Understand browser tasks
3. Control browser automatically
4. Handle UI dynamically
5. Verify results
6. Return reports/screenshots/logs

---

## EXAMPLE FLOW

Example user flow:

* Open telecom portal
* Click “TopUp Talk”
* Select amount 100
* Enter phone number
* Complete payment
* Open admin portal
* Login
* Search customer
* Verify balance
* Verify extra data
* Return final result

The AI agent should convert this into browser actions automatically.

## EXECUTION ENGINE

When execution starts:

1. Backend creates execution record (stored as filesystem artifact or kept in-memory)
2. Sends task to local LLM
3. LLM generates browser reasoning
4. Browser agent executes actions
5. Logs stream back to frontend
6. Screenshots saved to filesystem
7. Final result stored as an execution artifact
