============================================
 QA Automation Agent - System Requirements
============================================

1. PYTHON
   Version : 3.10 or higher
   Download: https://www.python.org/downloads/
   Note    : Check "Add Python to PATH" during install

2. NODE.JS
   Version : 18 or higher
   Download: https://nodejs.org/en/download
   Includes: npm (no separate install needed)

3. OLLAMA
   Version : Latest
   Download: https://ollama.com/download/windows
   Note    : Install and run once before starting the app

4. OLLAMA MODELS (pull after installing Ollama)
   LLM Model    : ollama pull qwen2.5:0.5b     (~400 MB)
   Vision Model : ollama pull moondream:latest  (~1.7 GB)

5. PLAYWRIGHT CHROMIUM (auto-installed by backend setup)
   Command: python -m playwright install chromium

============================================
 How to Start
============================================
   1. Install Python, Node.js, Ollama (links above)
   2. Pull Ollama models (commands above)
   3. Open terminal in project folder and run:

      Backend  : cd backend && venv\Scripts\uvicorn app.main:app --reload --port 8000
      Frontend : cd frontend && npm install && npm run dev

   4. Open browser: http://localhost:3000
   Login: admin / admin123
